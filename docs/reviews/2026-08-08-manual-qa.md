# Ручная QA Recap — подтверждения 2026-08-08

Датированный снимок поведения, проверенного владельцем в живом Windows-приложении или на реальных
внешних компонентах. Открытые проверки из прежнего QA-регистра перенесены в
[`docs/issues/roadmap.md`](../issues/roadmap.md) как REL-015…017.

## Подтверждено

- Отмена во время повторной суммаризации даёт `cancelled`, transcript сохраняется; отмена наступает
  после возврата LLM-вызова, что соответствует документированной гранулярности.
- Отмена во время суммаризации полного run даёт `cancelled`, transcript остаётся на диске.
- Отмена загрузки CUDA не создаёт completion sentinel, следующий запуск предлагает загрузку снова.
- SHA-256 проверка CUDA wheels проходит на настоящих пакетах.
- OpenAI принимает `json_schema`: в bridge log нет деградации на `json_object`.
- Правка plain summary сохраняется, открывается из истории и экспортируется без потери структуры.
- Ollama pull модели продолжался более пяти минут и не был ошибочно оборван idle timeout.
- История корректно окрашивает шаги для non-full режимов.
- `save_summary` сохраняет обычную пользовательскую правку в разрешённый путь.
- Экспорт при повреждённом base JSON восстанавливается из текста.
- Раздельные `recap-bridge.log` и `recap-bridge-serve.log` создаются одновременно.
- Tailwind 4 визуально проверен: границы, focus state и тени не показали регрессий.
