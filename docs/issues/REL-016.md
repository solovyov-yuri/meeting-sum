# REL-016: Bundled ffmpeg не проверен в portable-поставке

## Проблема

Поиск `ffmpeg.exe` рядом с `Recap.exe` покрыт тестом на искусственной frozen-раскладке, но полный
run ни разу не выполнен из реально собранной portable-папки с произвольной рабочей директорией.

## Доказательства

`scripts/build-portable.ps1 -Ffmpeg` копирует бинарник рядом с GUI, а bridge находится в подпапке.
Раньше этот layout требовал ручного `PATH`; живого подтверждения исправленной резолюции нет.

## Почему это важно

Desktop full mode всегда выполняет preprocessing. Ошибка поиска ffmpeg блокирует основной сценарий
portable-поставки, даже если транскрибация и LLM настроены правильно.

## Варианты решения

1. **Рекомендуется:** собрать portable с `-Ffmpeg`, запустить через ярлык с другой рабочей папкой и
   выполнить короткий full run.
2. Добавить packaging smoke test, запускающий frozen bridge из собранной раскладки; GUI-run всё
   равно остаётся ручной границей.

## Как проверить исправление

Собрать с `-Ffmpeg <path>`, создать ярлык на `Recap.exe` с рабочей папкой `C:\` и выполнить полный
run. Preprocessing проходит без системного ffmpeg в `PATH`.
