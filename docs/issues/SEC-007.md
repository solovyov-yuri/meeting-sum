# SEC-007: Незскоуплённая запись файлов из webview (save_summary / export_summary)

## Проблема

Модель угроз проекта явно считает XSS в webview реальным риском: ради этого `read_text` скоуплен
до путей из истории и data-dir (`_is_readable_path`, комментарий «SEC-003» в коде). Зеркальная
операция записи так не ограничена:

- `save_summary` (`desktop_bridge.py:545`): `summary_path = Path(payload["summary_path"])`,
  единственная проверка — `summary_path.parent.is_dir()`. Перезаписывает `summary_path` и создаёт
  соседний `{stem}.json` **где угодно**, содержимое (`summary_text`) полностью контролируется
  вызывающим. Пример эскалации: `%APPDATA%\...\Startup\x.bat` — каталог существует, проверка
  проходит.
- `export_summary` (`desktop_bridge.py:444`): каталог проверяется (`target_dir.is_dir()` — фикс
  SEC-003), но `base_name` из payload не санитизируется: `target_dir / f"{base_name}_summary.md"`
  с `base_name = "..\\..\\evil"` выводит запись за пределы выбранного диалогом каталога — обход
  того самого фикса.

## Доказательства

Оба фрагмента прочитаны в этом ревью (2026-07-05): в `save_summary` нет обращений к
`_history_referenced_paths`/`_is_readable_path`; в `export_summary` `base_name` конкатенируется
без `Path(base_name).name`.

## Почему это важно

XSS в webview (отрисовка LLM-выхода/истории) превращается в произвольную запись файлов от имени
пользователя — ровно тот класс эскалации, который SEC-003 закрыл для чтения. Непоследовательная
модель безопасности хуже отсутствующей: читатель кода полагает, что границы уже проведены.

## Варианты решения

1. **(Рекомендуется)** `save_summary`: разрешать запись только в пути, на которые ссылается
   история (`summary_path` записей из `_history_referenced_paths()`), — UI ровно так его и
   использует. `export_summary`: отклонять `base_name`, содержащий `/`, `\` или `..`
   (или просто брать `Path(base_name).name`).
2. Альтернатива: разрешать запись только внутри data-dir + каталогов, упомянутых в истории.

## Как проверить исправление

Unit-тесты: `save_summary` с путём вне истории → `ValueError`; `export_summary` с
`base_name="..\\x"` → `ValueError`; сохранение/экспорт из живого UI продолжают работать.
