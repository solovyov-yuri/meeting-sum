# REL-003: Мигающее консольное окно на каждый вызов моста

## Проблема

GUI-приложение (`windows_subsystem = "windows"`) спавнит консольного ребёнка (python.exe) без
`creation_flags` — Windows выделяет видимое консольное окно на **каждый** spawn: `get_settings`,
`get_history`, каждый запуск, каждое сохранение настроек.

**Гипотеза** (стандартное поведение Windows; не проверено на release-сборке — Rust-тулчейна в этом
окружении нет). Подтверждение: собрать release и кликнуть по любому экрану.

## Варианты решения

1. **Рекомендуется:** `#[cfg(windows)] cmd.creation_flags(0x08000000 /* CREATE_NO_WINDOW */)` в `bridge_command`.
2. `pythonw.exe` — хрупко, не рекомендуется.

## Как проверить исправление

Release-сборка: ни одного мигающего окна при навигации и запусках.
