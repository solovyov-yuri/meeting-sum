# REL-007: Retry может не срабатывать на ошибках посреди стрима

## Проблема

`_RETRYABLE = (openai.APITimeoutError, openai.APIConnectionError, openai.InternalServerError)`.
Ошибки времени запроса SDK оборачивает, но ошибки, возникающие при итерации SSE-стрима, в ряде
версий openai-python всплывали как `httpx.ReadError`/`httpx.RemoteProtocolError` — мимо retry.
Для CLI `summarize` это провал всего (возможно многочасового) запуска на последнем шаге; в
десктопе смягчено `partial_success` (транскрипт сохранён).

**Гипотеза** — подтверждается обрывом соединения во время стриминга токенов на установленной
версии SDK (uv.lock: openai 2.36.0).

## Варианты решения

1. **Рекомендуется:** добавить `httpx.HTTPError` в `_RETRYABLE`.
2. Проверить, что установленная версия SDK оборачивает итерационные ошибки, и задокументировать.

## Как проверить исправление

Тест: mock-стрим, кидающий `httpx.ReadError` на втором чанке, → происходит retry.
