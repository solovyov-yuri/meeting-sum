# DEP-002: Дрейф мажорных версий фронтенд-тулчейна

## Проблема

`vite ^5.4.11` (v6 — ноя 2024, v7 — 2025; ветка 5 вне окна фиксов), `vitest ^2.1.8` (v3+ текущий,
следует за мажорами Vite), `tailwindcss ^3.4.17` (v4 GA янв 2025), `react ^18.3.1` (React 19 —
дек 2024). Ничего критично-EOL по отдельности, но vite+vitest связаны и выпадают из окна
поддержки; чем дольше ждать, тем дороже миграция (особенно Tailwind 4).

По `@tauri-apps/*` 2.x и `Cargo.toml` (tauri 2, serde 1) действий не требуется — всё актуально.

## Варианты решения

1. Пакетно поднять vite 6/7 + vitest 3; Tailwind 4 и React 19 — отдельными опциональными миграциями.

## Как проверить исправление

`npm run build && npm run test` зелёные на новых мажорах.
