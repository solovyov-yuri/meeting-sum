# REL-002: ffmpeg без `-nostdin` и timeout

## Проблема

`preprocess_audio` вызывает `subprocess.run(...)` без `stdin=subprocess.DEVNULL`, без `timeout=`,
и `_build_cmd` не добавляет `-nostdin`. ffmpeg наследует stdin родителя: в интерактивном CLI может
перехватывать ввод терминала и на некоторых промптах блокироваться навсегда; верхней границы
времени работы нет — заклинивший ffmpeg вешает `transcribe`/`run`/`batch` бесконечно. (В
десктопном мосте stdin — закрытый JSON-пайп, там ffmpeg видит EOF; это в основном CLI-проблема.)

Инъекции команд нет: argv-список без `shell=True`, все интерполируемые значения — валидированные числа из конфига (проверено).

## Варианты решения

1. **Рекомендуется:** добавить `"-nostdin"` в `_build_cmd` и `stdin=subprocess.DEVNULL` в вызов.
2. Дополнительно щедрый `timeout=` с маппингом `TimeoutExpired` → `PreprocessingError`.

## Как проверить исправление

`grep -n "nostdin\|DEVNULL\|timeout" src/preprocessing.py`; существующие тесты preprocessing зелёные.
