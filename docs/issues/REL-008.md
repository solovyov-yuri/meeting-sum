# REL-008: mkdir выходного каталога вне error boundary

## Проблема

`_ensure_output` (`cli.py:55-61`) делает `path.parent.mkdir(parents=True, exist_ok=True)` без
try — ошибка прав на создание каталога печатает сырой трейсбэк, тогда как все остальные IO-пути
CLI дают чистое сообщение + `typer.Exit(1)`. Нарушение собственного правила проекта «cli.py —
единственный error boundary».

## Варианты решения

1. Обернуть в `try/except OSError` → сообщение + `typer.Exit(1)`.

## Как проверить исправление

`recap run audio.mp3 -o /root/forbidden/out.txt` (или эквивалент) — чистая ошибка, exit 1.
