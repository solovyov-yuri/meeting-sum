# Предложения по развитию Recap

Продуктовый backlog: возможности, которых в Recap ещё нет, но которые рассматриваются для
развития. Одно предложение — один нумерованный файл.

**Статус живёт только здесь.** Файлы предложений описывают замысел и критерии готовности, но не
содержат отметок реализации. Техдолг и дефекты находятся в
[`docs/issues/roadmap.md`](../issues/roadmap.md). Граница между списками зафиксирована
[ADR-0001](../adr/0001-record-of-work-taxonomy.md).

Статусы: `planned -> in-progress -> shipped`, плюс `deferred` и `dropped` с причиной в отметке.

| № | Предложение | Статус | Отметки |
|---|---|---|---|
| [0001](0001-agent-integration.md) | Интеграция Recap с пользовательскими агентами | planned | MCP/typed gateway, устойчивые jobs, installer integration и privacy boundary |

У `planned`-предложения отсутствие реализации уже выражено статусом и не создаёт issue. Если
`in-progress` или `shipped` предложение не закрывает обещанный сценарий, оставшийся разрыв
оформляется как issue.
