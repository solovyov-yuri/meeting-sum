# Долг ручной проверки

Что сделано, но ни разу не проверено вживую на Windows. Агент дописывает строку сюда при каждом
изменении, поведение которого нельзя проверить из WSL (GUI, CUDA, живой LLM/Ollama). Пользователь
вычёркивает строку после прогона — удаляет её или переносит в «Проверено».

Формат: `дата — что сделано — как проверить`.

## Ожидает прогона

- 2026-08-08 — **отмена на фазе распаковки CUDA** (раньше опрашивался только этап загрузки) — в
  прогоне 2026-08-08 отмена сработала на этапе загрузки, до распаковки дело не дошло, так что сама
  правка ещё не проверена. Нужно: снести `%APPDATA%\app.recap.desktop\cuda`, начать загрузку GPU и
  нажать «Отмена» уже на сообщении «Распаковка …» (оно появляется между двумя пакетами). Ожидание:
  остановка, сентинел `.recap-cuda-complete` не создан, при следующем запуске загрузка предлагается
  снова.
- 2026-08-08 — **детекция NVIDIA GPU, ветка «карты нет»** — покрыта только моками (на этой машине
  карта есть). Проверять на машине без NVIDIA либо здесь через тумблер `RECAP_ASSUME_GPU=0`:
  `device=cuda` → понятная ошибка без загрузки 2 ГБ, `device=auto` → прогон на CPU с предупреждением.
- 2026-08-08 — **портативный ffmpeg** — в собранной портативной сборке `ffmpeg.exe` лежит рядом с
  `Recap.exe`, а мост запускается из подпапки `recap-bridge\`, которую ОС не просматривает. Раньше
  требовалась ручная правка `PATH`. Проверить: собрать с `-Ffmpeg <путь к ffmpeg.exe>`, создать ярлык
  на `Recap.exe` с «Рабочей папкой», указывающей куда угодно **кроме** папки приложения (например
  `C:\`), запустить приложение этим ярлыком и прогнать **полный** режим (он всегда вызывает ffmpeg).
  Ожидание: предобработка проходит, а не падает с «ffmpeg not found».
- 2026-08-08 — **UTF-8 на stdin моста** — касается только прямого запуска `recap-bridge` мимо
  приложения (из приложения Rust выставляет `PYTHONUTF8=1`, и путь и так рабочий). Проверить в чистом
  PowerShell без `PYTHONUTF8`/`PYTHONIOENCODING`: положить рядом `payload.json` в UTF-8, где
  `audio_path` — путь с кириллицей, и выполнить
  `Get-Content payload.json -Raw -Encoding utf8 | .\recap-bridge.exe run_recap`. Ожидание: в ответе
  нормальный путь, а не кракозябры и не traceback `UnicodeDecodeError`. Низкий приоритет — сценарий
  отладочный.
