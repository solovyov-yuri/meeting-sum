# Долг ручной проверки

Что сделано, но ни разу не проверено вживую на Windows. Агент дописывает строку сюда при каждом
изменении, поведение которого нельзя проверить из WSL (GUI, CUDA, живой LLM/Ollama). Пользователь
вычёркивает строку после прогона — удаляет её или переносит в «Проверено».

Формат: `дата — что сделано — как проверить`.

## Ожидает прогона

- 2026-08-08 — отмена во время суммаризации (`resummarize_one` наконец видит cancel-флаг) —
  запустить «Повторить суммаризацию» на длинном транскрипте, нажать «Остановить»: прогон должен
  закончиться статусом `cancelled`, транскрипт остаться в истории, саммари не перезаписаться.
- 2026-08-08 — побочный эффект того же изменения: «Остановить» во время суммаризации в **полном**
  прогоне теперь даёт `cancelled`, а не `success` — проверить, что UI и история это показывают.
- 2026-08-08 — отмена на фазе распаковки CUDA (раньше опрашивался только этап загрузки) —
  на машине без прогретого кэша нажать «Отмена», когда идёт «Распаковка…»: должна остановиться,
  сентинел не появиться, при следующем запуске загрузка предлагаться снова.
- 2026-08-08 — sha256-верификация CUDA-колёс — просто пройти загрузку GPU-библиотек целиком:
  она не должна ломаться на честных колёсах (проверялась только на фейковых zip'ах).
- 2026-08-08 — `json_schema` в `response_format` — прогнать саммари через OpenAI/xAI и поискать в
  `recap-bridge.log` строку `Provider rejected response_format=json_schema`. Если она есть —
  каждый структурированный прогон платит лишний round-trip, схему надо делать strict-совместимой.
- 2026-08-08 — plain text как редактируемая форма (коммит `0ac5799` + сегодняшние правки парсера) —
  отредактировать саммари в приложении, сохранить, переоткрыть из истории, экспортировать:
  структура не должна поехать.
- 2026-08-08 — таймаут Ollama-pull (`PULL_IDLE_TIMEOUT = 300 с`) — скачать крупную модель: пауза на
  проверке контрольных сумм не должна обрывать загрузку.
- 2026-08-08 — раскраска шагов при открытии истории теперь учитывает режим прогона — открыть из
  истории упавший прогон в режиме «Саммари» и в режиме «Подготовка»: видимое кольцо должно быть
  красным («Ошибка»), а не «Ожидает»; полный прогон — как раньше (ошибка на «Транскрибации»,
  частичный успех — на «Суммаризации»).
- 2026-08-08 — «Сохранить» теперь может **отказать**: запись разрешена только по `summary_path` из
  истории — проверить, что обычное редактирование саммари (после прогона и после открытия записи из
  истории) сохраняется как раньше, а не упирается в ошибку.
- 2026-08-08 — экспорт при повреждённом `.json` — испортить `*_summary.json` руками и нажать
  «Экспорт»: должен пройти из текста, а не упасть; при пустом тексте — понятная ошибка и ноль
  созданных файлов.
- 2026-08-08 — детекция NVIDIA GPU перед загрузкой CUDA — ветка «карты нет» покрыта только моками
  (на этой машине карта есть). Нужна проверка на машине без NVIDIA: `device=cuda` → понятная ошибка
  без загрузки, `device=auto` → прогон на CPU с предупреждением. Аварийный тумблер, если детекция
  ошибётся: `RECAP_ASSUME_GPU=1`.
- 2026-08-08 — портативный ffmpeg — собрать с `-Ffmpeg` и запустить ярлыком с другим «Рабочей
  папкой»: полный режим должен найти `ffmpeg.exe` рядом с приложением без правки `PATH`.
- 2026-08-08 — `_force_utf8_io` теперь переконфигурирует и `stdin` (кириллица в `audio_path` при
  прямом запуске моста) — механика проверена из WSL подстановкой `PYTHONIOENCODING=cp1251`, но
  настоящая локальная кодировка по умолчанию здесь недостижима (в среде принудительно стоит
  `PYTHONIOENCODING=utf-8`). Проверить в чистом PowerShell без `PYTHONUTF8`/`PYTHONIOENCODING`:
  `recap-bridge run_recap < payload.json`, где `audio_path` — путь с кириллицей; в ответе должен
  быть нормальный путь, а не кракозябры и не traceback `UnicodeDecodeError`.
- 2026-08-08 — лог моста разделён на два файла (`recap-bridge-serve.log` для воркера,
  `recap-bridge.log` для одиночных команд) — прогнать приложение и убедиться, что оба появляются и
  что прогон пишется именно в serve-файл.
- 2026-07-02 — Tailwind 4 — визуальный обзор границ, focus-ring и теней в запущенном приложении
