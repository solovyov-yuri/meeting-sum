# Architecture Decision Records

ADR фиксирует решение, которое ограничивает будущую работу, причины выбора и отвергнутые
альтернативы. Обычным исправлениям и локальным рефакторингам ADR не нужен.

После принятия запись не переписывается: изменившееся решение получает новый ADR, а старый
помечается `superseded by NNNN`. Новый файл создаётся из [0000-template.md](0000-template.md),
получает следующий свободный четырёхзначный номер и добавляется в таблицу.

| № | Решение | Статус | Дата |
|---|---|---|---|
| [0001](0001-record-of-work-taxonomy.md) | Separate decisions, technical debt, proposals and review snapshots under docs/ | accepted | 2026-08-30 |
