# SEC-003: Нескоуплённые файловые IPC-примитивы

## Проблема

`read_text(path)` читает любой файл на диске по пути, присланному из webview
(`desktop_bridge.py:259-269`); `export_summary` делает `mkdir(parents=True)` и пишет в любой
каталог (`:287-297`). Оба экспонированы как Tauri-команды. Для задуманного UI это безобидно, но в
связке с отключённым CSP ([[SEC-002]]) одна XSS = произвольное чтение/запись файлов.

Попутно (reliability): `read_text` ловит только `OSError` — `UnicodeDecodeError` на бинарном файле
улетает в общий boundary с сырым сообщением.

## Варианты решения

1. **Рекомендуется:** ограничить `read_text` путями из history.json + каталогом данных приложения; для `export_summary` — требовать существующий каталог из диалога сохранения. Плюс `errors="replace"` либо перехват `UnicodeDecodeError`.
2. Оставить как есть, но закрыть [[SEC-002]] (defense-in-depth останется однослойной).

## Как проверить исправление

Вызов `read_text` с путём вне разрешённого множества возвращает ошибку; чтение бинарного файла не роняет команду; существующие экраны (просмотр транскрипта/суммари, экспорт) работают.
