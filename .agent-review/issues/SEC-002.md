# SEC-002: CSP отключён в Tauri

## Проблема

`tauri.conf.json` → `"security": { "csp": null }`. Webview отображает контент, на который может
влиять атакующий (LLM-вывод и транскрипты: prompt-injection через аудио встречи → текст суммари).
Сегодня прямой эксплуатации нет — React экранирует, `dangerouslySetInnerHTML`/`innerHTML` в
`desktop/src` отсутствуют (проверено grep) — но это единственная линия обороны.

## Почему это важно

Без CSP любой инжектированный скрипт исполняется без ограничений, а в связке с нескоуплённым
`read_text`/`export_summary` ([[SEC-003]]) единственная XSS превращается в чтение/запись
произвольных файлов.

## Варианты решения

1. **Рекомендуется:** строгий CSP: `default-src 'self'; connect-src ipc: http://ipc.localhost` (возможно, пара итераций под Vite dev-режим).
2. Оставить null, но письменно зафиксировать почему — не рекомендуется.

## Как проверить исправление

`tauri.conf.json` содержит непустой csp; десктоп-приложение запускается и все экраны работают (dev и release).
