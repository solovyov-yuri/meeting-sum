# DEP-003: CUDA-wheels — безусловные install-time зависимости

## Проблема

`nvidia-cublas-cu12>=12.9.2.10` и `nvidia-cudnn-cu12>=9.22.0.52` ставятся всем — включая
пользователей `device: cpu` (режим явно задокументирован в README) и тех, кому нужен только
summarize/bridge-путь. Это ~1–2 ГБ на диске. Код их отсутствие уже терпит:
`whisper._set_cuda_paths()` гардит каждый preload через `if lib_path.exists()`.

**Гипотеза (macOS):** `nvidia-*-cu12` публикует только Linux/Windows-wheels — `uv sync` на macOS,
вероятно, падает целиком, хотя CLAUDE.md называет проект кроссплатформенным. Подтверждение:
резолв на macOS или проверка списка wheels на PyPI.

## Варианты решения

1. **Рекомендуется:** optional extra `recap[cuda]` + `uv sync --extra cuda` в README.
2. Минимум: environment markers (`sys_platform != 'darwin'`).

## Как проверить исправление

Свежая установка без extra не тянет nvidia-wheels; `recap transcribe --device cpu` работает.
