# DOC-002: README не знает о десктоп-приложении

## Проблема

В корневом README нет ни «desktop», ни «Tauri», ни `recap-bridge`; установка/использование
покрывают только пять CLI-команд. Репозиторий при этом содержит второй entry point
(`recap-bridge`, `pyproject.toml:24`) и полноценное десктоп-приложение со своим README.

## Варианты решения

1. Короткая секция «Desktop app» со ссылками на `desktop/README.md` и `docs/desktop-tauri-spec.md`.

## Как проверить исправление

`grep -i "desktop" README.md` находит секцию.
