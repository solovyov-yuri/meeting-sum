# DEP-004: Слишком свободный floor для openai

## Проблема

Заявлено `openai>=1.0`, uv.lock резолвит 2.36.0. Код опирается на поведение 2.x (streaming context
manager, `extra_body`); свежий резолв в другом окружении может легально поставить 1.0.x. Lock-файл
смягчает риск в ежедневной работе, но не для потребителей wheel.

## Варианты решения

1. Ужесточить до `openai>=2,<3`; рассмотреть тот же стиль major-cap для `faster-whisper`.

## Как проверить исправление

`grep openai pyproject.toml`; тесты зелёные после ре-резолва.
